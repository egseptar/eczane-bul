# 🏥 Eczane Bul — Nöbetçi ve En Yakın Eczane Bulma Uygulaması

Modern, kurumsal arayüzlü ve konum tabanlı Nöbetçi Eczane arama Flutter uygulaması.

---

## 🌟 Özellikler

- 📍 **Konum Tabanlı Arama:** Anlık konumunuza göre en yakın nöbetçi ve açık eczaneleri listeleme.
- 🗺️ **Google Maps Entegrasyonu:** Eczane konumlarını harita üzerinde görüntüleme ve yol tarifi alma.
- 🌙 **Karanlık Mod (Dark Mode) Desteği:** Şık, göz yormayan modern karanlık mod teması.
- 💊 **Detaylı Eczane Bilgileri:** Telefon, adres, mesafe ve çalışma saatleri detayları.
- ⚡ **Hızlı API Servisi:** NosyAPI & CollectAPI yedekli nöbetçi eczane veri entegrasyonu.

---

## 🚀 Başlangıç

### Gereksinimler
- **Flutter SDK:** ^3.0.0
- **Dart SDK:** ^3.0.0

### Kurulum

1. Repoyu klonlayın:
   ```bash
   git clone https://github.com/egseptar/eczane-bul.git
   ```

2. Proje dizinine gidin:
   ```bash
   cd eczane-bul
   ```

3. Bağımlılıkları yükleyin:
   ```bash
   flutter pub get
   ```

4. Uygulamayı çalıştırın:
   ```bash
   flutter run
   ```
